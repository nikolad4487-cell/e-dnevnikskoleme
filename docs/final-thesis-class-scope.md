# Završni radovi po razredu

- Modul koristi trenutačno odabrani razred iz aplikacije.
- Prijave, učenici, rasporedi obrane i arhiva filtrirani su po `selectedClassId`.
- U modalu rasporeda obrane razred se više ne bira ručno.
- Razred i razrednik prikazuju se automatski za trenutačno odabrani razred.
- Razredi s istim nazivom u različitim školskim godinama ostaju odvojeni jer se koristi ID razreda.
